# Saboteur

The Saboteur LLC parent landing page. Creator-first software — what the company is, the three tenets it operates by, and the products shipping under it.

**Status:** Live
**Domain:** saboteur.dev
**Sub-brand:** — (parent tier; SAB/works and SAB/labs sit beneath it)

## Sections

Nav · Hero · Mission (+ tenets) · Products · Status · Legal footer

There is no contact form on this page. The footer links to `contact@saboteur.dev` directly.

## Developing

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # production build → dist/
```

## Deploying

Hosted on Cloudflare Pages. Push to `main` to deploy. Preview deploys on all branches.
